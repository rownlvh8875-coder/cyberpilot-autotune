# Kernel lifetime implementation entry gates

Source feasibility only. `NO_GO_CURRENT_PROFILE` is the current qualification
verdict; `CONDITIONAL_DESIGN_ONLY` names a route to investigate, not authorization
or evidence that any runtime path exists. All9 operational permissions remain false.

## One bounded future implementation, not a general observer

Recommended next single task: **disposable-guest raw FD lifecycle source prototype**.
Use the same exact Linux source package and a separately identified guest binary;
small fixed harmless descriptor operations, no arbitrary workload/real compiler,
network, host tracing or vehicle. Record raw lifetime/effect events and explicit
loss counters without a PR35 semantic adapter. Its success would be a diagnostic
experiment only, not kernel/consumer/build/PR30/application qualification.

This recommendation is not started by the feasibility work. A future implementation
must explicitly establish its bounded setup and artifact identities. If it needs
unavailable build/toolchain/source inputs, it stops and reports them rather than
substituting a host kernel or silently changing the source cohort.

## Ordered entry gates

| Gate | Required before claiming that property | Fail-closed result |
|---|---|---|
| G1 exact source/binary | source/archive/patch/config/toolchain/kernel and collector digests, build provenance and boot scope; actual available instrumentation context | identity unavailable; no runtime-source equivalence claim |
| G2 supported raw effect set | exact allocation/publication/replace/flags/remove/detach/free sites and failure variants for each admitted path; source-issued cookies before reuse | missing hook/effect invalidates affected capture, no synthetic generations |
| G3 scope entry/root | source arm before managed root creation, inherited/boot lifetime treatment, every shared owner/external handle source covered or genuinely excluded | root/closure unavailable; no late snapshot promoted to birth |
| G4 no invisible serialization | preserve actual effect order, operation interval and observer interventions; no lock added solely to force serialized output | perturbed execution labeled; not natural execution evidence |
| G5 copy/exec cut | whole-scope mutator and in-flight-install quiescence, reserved slot proof, full copy/close delta with raw provenance, or separately designed interleaved profile | PR35 mapping unavailable; keep raw diagnostic only |
| G6 independent loss accounting | count all required attempts before fallible emission; reserve/commit/discard/pending/delivery balance, source+CPU cohort, overflow/reset/recursion handling | lost/unknown counter invalidates lossless profile, actual counts not default0 |
| G7 arm/drain/hotplug | all-source acknowledged arm cut before workload, stop new admitted effects, quiesce callbacks, dispose outstanding reservations, flush transport and prove complete end watermark on every participating/idle CPU | no complete window claim; bounded timeout means failure, not proof of drain |
| G8 terminals/perturbation | actual task detach versus reap, namespace destruction versus storage resize, file terminal versus close/fput and actual observer references | terminal identity unavailable, no inference from known count0 |
| G9 independent review | exact source/binary/evidence cohort, adversarial reserve failures/loss/duplicates/ABA/alias/exec/racing copy tests and fresh review; separate downstream qualification | diagnostic experiment remains unqualified |

G1/G2 are planning prerequisites to meaningful prototype measurements, not existing
completed gates. Later gates bound which conclusions a prototype may make. A run
can deliberately exercise a failed gate as a negative case without passing it.
No gate can be self-certified by a caller boolean or by this pure Python checker.

## Proposed raw record principles — not a wire/runtime implementation

- Include boot/session/source/collector/CPU cohort and receipt version separately.
- Assign source-side allocation cookies at actual admitted lifetime birth. Preserve
  old/new namespace, exact slot binding and operation ID; no pointer/PID/inode/hash
  substituted as persistent identity. Fail closed on cookie reuse/overflow/reset.
- Record begin/effect/end/disposition relationships without pretending all kernel
  effects possess a single global linearization. Reservation/arrival time is not
  effect time. Wire carries no raw addresses, process names or pathname identities.
- Distinguish attempted, successfully reserved, committed, discarded, pending,
  delivered and independently observed loss; do not convert a dropped counter into
  a lossless source receipt. A failure before accounting remains a coverage gap.
- Static boot objects, failed initialization/failed fork cleanup and noaccount/
  backing files need explicit scope semantics. Do not assign a second live lifetime
  on syscall return or keep kernel objects referenced solely to prevent identity ABA.
- Do not dereference freed objects to emit a terminal record. Hook safety, lock
  nesting, allocator recursion, preemption/NMI and collector interference require
  source/binary-specific proof; this design does not prescribe an unsafe callback.
- After a failed capture, distinguish evidence invalidation from target execution
  enforcement. This observer is not a sandbox, rollback mechanism or watchdog.
